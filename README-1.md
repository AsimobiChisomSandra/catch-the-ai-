# Catch the AI · Answer Checker

A free, no-login web page that helps young people check AI answers before they trust them.

**Live page:** https://asimobichisomsandra.github.io/catch-the-ai/

## What it does
1. The student types the question they asked the AI and pastes the answer.
2. The page shows a traffic light and marks the details worth checking: numbers, dates, quotes, sources, named experts, amounts and big claims.
3. Each marked detail has a "Search this" button that searches the question together with the detail, and a dropdown to record what they found.
4. A short feedback question and a copyable **Check Receipt** finish the check.

## Honest limits
- It has no AI inside and uses simple rules. It cannot tell if an answer is true.
- A highlighted part is a place to look, not a proven mistake. A green light never means correct.
- Nothing is sent anywhere. The page works offline once it has opened.
